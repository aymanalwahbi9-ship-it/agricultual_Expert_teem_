# نظام الخبير الزراعي

نظام خبير زراعي تعليمي مبني باستخدام Laravel، يساعد المستخدم على إدخال بيانات التربة ورفع صورة للنبات للحصول على نتيجة إرشادية مبنية على قاعدة معرفة وقواعد تحليل محددة.

## فكرة المشروع

يهدف النظام إلى مساعدة المزارع في الحصول على إرشادات أولية حول حالة النبات والتربة من خلال:

- اختيار المحصول.
- إدخال بيانات التربة.
- رفع صورة للنبات.
- تحليل بيانات التربة.
- البحث في قاعدة المعرفة الزراعية.
- عرض نتيجة إرشادية وتوصيات مناسبة.
- حفظ سجل التشخيصات السابقة.

تحليل الصورة في الإصدار الحالي محاكاة تعليمية، ولا يمثل تشخيصًا زراعيًا قطعيًا.

## التقنيات المستخدمة

- Laravel
- PHP
- Eloquent ORM
- SQLite
- Blade
- Tailwind CSS
- Vite
- PHPUnit
